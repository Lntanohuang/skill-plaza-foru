# 05 · 广东在招岗位数据记录（内部岗位库快照）

数据源：内部招聘岗位数据库只读快照（账号、密码、地址、端口等连接信息已清除，不上传）。
数据时点：2026-09-20 查询。统计方式：全量拉取本地后离线计算。

---

## 1. 口径定义

| 项 | 值 |
|---|---|
| 地域口径 | 企业地址表 `c_company_address.province='广东省'` 且 `deleted=0`，join 主表 `p.company_archive_id = a.company_id` |
| 在招口径 | `c_company_position.publish_state='PUBLISHING'` 且 `deleted=0` |
| 去重规则 | join 行数 1,870,816，按 `p.id` 去重后为统计基数（多址企业产生重复行 328,301） |
| 统计基数 | 1,542,515 条（岗位）；479,097 家（企业）；572,015 家（广东有地址的企业） |
| 时间口径 | 库内无岗位真实发布时间。`create_time`=爬虫导入批次：2026-06 占 52.8%（814,754）、2026-07 占 38.0%（586,654）、2025-04/05 占 4.3%（65,929，河北高校渠道）。`update_time` 2026-08/09 仅 43 条 |
| 薪酬单位 | K/月，中值 =(min_salary+max_salary)/2 |
| JD 全库词频 | 1/40 等距抽样（45,363 条）推全，相对误差约 ±1%；AI 切片为精确值 |
| JD 词匹配 | 中文子串匹配；拉丁词按词边界正则（`(?<![a-z])word`，含尾数字如 ros2）；SQL 计入 my/no/postgre 变体 |

## 2. 字段清单（11 列 schema 对照）

| 需求字段 | 库内字段 | 状态 |
|---|---|---|
| 岗位名称 | `c_company_position.name` varchar(255) | 有，零缺失 |

| 学历要求 | `education` 枚举 | 有，零缺失 |
| 经验要求 | `experience` 枚举 | 有，脏值 WEWER23 151 条 |
| 薪酬区间 | `min_salary` / `max_salary` varchar | 有，数值覆盖 99.92% |
| JD 全文 | `description` longtext | 有，均值 316 字/中位 259 字 |

其他可用字段：`type`（招聘性质枚举）、`position_type`（岗位类型列表，逗号分隔）、`views/communicates/interested`（互动数）。主表 FULLTEXT 索引未带 ngram 分词，中文检索不可用，只能 `LIKE` 或导出本地。带日期后缀的备份快照表禁用。
