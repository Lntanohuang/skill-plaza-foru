- 状态：已实现（2026-09-23；真实 career-guidance 会话待回归）。
- 动机：就业指导的原始 Skill 同时描述了内部整理步骤和用户报告结构，模型容易把“建立输入摘要、证据表、待验证假设、事实/推断/建议标签”等工作材料原样带进最终回复。最终输出应服务求职者阅读和决策。
- 约定细节：
  - `.agents/skills/career-guidance/SKILL.md` 新增“最终回复是给用户看的”边界，禁止输出提示词、工具过程、内部清单、原始 JSON、schema 和执行说明；不确定性改用“已知依据、当前判断、需要核实”。
  - 输出默认从可执行结论开始，随后给依据、缺口/风险、建议、行动和核实问题；局部任务按需删减，不强行套完整报告。
  - `references/output-schemas.md` 的状态词改为用户可理解的“已具备、部分具备、待补强、信息不足”。
  - `web/server/lib/piRunner.ts:345-353` 的首轮直出指令同步强调用户报告边界；`web/server/lib/reportMeta.ts:188` 的侧车 claims 不再要求正文添加机器标签，侧车仍由服务端剥离。
- 成本与取舍：保留来源、时间、地域、口径和缺口信息，牺牲少量内部可观测措辞换取更清晰的用户报告；没有删除内部证据整理，只限制其不得原样展示。没有把所有报告强制成固定长模板，避免用户只要简历改写时输出冗余章节。
- 验证：已通过静态检查：Skill、README、输出结构和 pi 直出提示词均包含用户报告边界；服务端构建待运行，真实模型输出与侧车剥离待回归。
