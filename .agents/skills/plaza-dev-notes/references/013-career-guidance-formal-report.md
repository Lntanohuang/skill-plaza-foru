# 013 · 就业指导正式报告：岗位需求分析与简历修改建议

- 状态：已实现（2026-09-24；真实岗位库查询和浏览器回归待跑）。
- 动机：MVP 直出只强调结论、行动和侧车，用户无法看到岗位市场结构，也缺少可直接替换的简历改写内容。
- 约定细节：
  - 正式 career-guidance 报告固定包含结论、岗位需求分析、岗位匹配、简历修改建议和行动计划。
  - 岗位需求分析必须使用具体城市/岗位的 MySQL 岗位库查询；岗位量、排序、学历/经验/薪资结构等可量化数据在正文中以柱状图、线形图、折线图、堆叠柱状图、直方图或地图等合适的有效图表形式展示，并附筛选口径、样本范围和关键发现。SQL、查询过程和不足写入开发侧；数据不足时不生成对应图表。
  - `report-meta/2.marketAnalysis` 记录查询筛选、样本量、快照日期、指标/图表引用和分析缺口；`resumeReview` 记录简历优点、缺失证据和改写项。
  - 新增 `references/data/广州-Java后端实习岗位分析.md` 作为人工回填模板，不把未回填内容当作事实。
  - `piRunner` 不再使用“MVP 直出”措辞，首轮提示要求读取附件、查询岗位库并生成正式报告；用户正文仍不展示 `gaps/risks/evidence`。
- 成本与取舍：报告 token 和查询耗时增加；换取岗位建议可追溯、图表可复用和简历改写可执行。暂不让前端自行从 Markdown 正则抽取市场数字，避免口径错配。
- 后续扩展路线：在内网回归广州 Java 实习查询；把技能词频、岗位链接和企业信息补入岗位分析 Markdown；增加正文数字与 `marketAnalysis` 指标的一致性校验。
- 验证：前端构建、侧车解析和类型检查待运行；真实数据库查询和浏览器展示待验证。
