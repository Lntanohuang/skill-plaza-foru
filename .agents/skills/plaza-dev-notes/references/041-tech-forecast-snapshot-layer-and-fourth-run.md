## 成本与取舍

- **快照优先换秒级引用与跨会话可比**，代价是快照固化了 `roleTerms`（工具默认 `["后端","服务端","开发"]`），机器人域被收窄为软件岗，高职对口的运维/调试/标注切片仍必须实时补查——快照并没有省掉全部查询。**否决方案**：只引用快照不补查（被否决：会漏掉本次报告最关键的高职适配证据）。
- **偏离一次性生成脚本**：5 图手写坐标换取少一次临时脚本与一轮回读；接受当前规模，但明确后续若图数继续增长或需要调参，恢复脚本生成（否则坐标维护成本会反超查询成本）。
- 复现确认：不再重复 035/037/039 已否决的方案（手写大规模 SVG 坐标、把“广东省”当 `city` 传参、默认/显式 `roleTerms` 混用比较）。
