# 043 · 纺织服装快照（含公开来源节）与 web-search 检索源修复

- 状态：已实现（guangdong-textile.md 交付审阅；web-search.mjs 检索源兜底已实测）。
- 动机：用户要求生成纺织行业报告并先建中间产物，预判"数据库对这个行业覆盖有限，更需要网上搜索"。探库证实：广东省「纺织」仅 8 条、「缝纫」1 条，浙江 1 条、江苏 4 条；最强切片为「面料」680 条（广州 159/深圳 158/东莞 130/佛山 113，对应中大面料市场辐射）与「服装」74 条。制造业一线岗位大概率不在本库（招聘平台型数据源偏白领岗）。
- 约定细节：
  - **切片结构特例**：纺织领域不做"新兴 vs 传统对照"（库内无新兴样本），改为**产业链上下游对照**——面料（中游，主切片）vs 服装（下游）；报告的新兴方向预测（智能制造、数码印花、数字化车间运维等）以公开来源与分析推断为主，快照头部显式声明该边界。
  - **快照新增「公开来源摘要」节**：固化联网检索成果（要点+标题+网站+日期），首期 3 条：中纺联会长年度综述（cntac.org.cn 2025-12-30，"优化提升"重点产业/数字孪生/具身智能进工厂）、中纺联产业集群会议（2025-11-24，产能向中西部转移）、新华网江西频道德安 5G 智慧工厂案例（2024-09-29，ERP/MES+自动化车间，省 30% 人力）。检索规则更新进 `technology-snapshots.md`：纺织建议词 + 行业权威源（cntac.org.cn）。
  - **web-search.mjs 检索源修复**：cn.bing 对本机自动化请求全面反爬降级（cookie 引导无效，返回完全无关结果，如随机明星八卦）；新增 **so360 兜底引擎**（`so.com/s` 解析 `res-title` 块，`/link?m=` 重定向页解析 `window.location.replace` 明文真实地址）+ **相关性判别**（查询词 token 未出现在任何标题/摘要即判降级，自动切换 360）。cn.bing 侧加 cookie 引导与 setmkt 参数（当前仍降级，保留作为首选引擎待其恢复）。
  - 新华网主站对无 referer 的脚本请求返回 403 感谢页，**地方频道（jx.xinhuanet.com）可直接抓取**；抓取失败时改用 curl 带 Referer 或换地方频道版本。
- 成本与取舍：360 兜底换取检索可用性，代价是结果中文库类站点占比高（人人文库/原创力），需人工筛选权威引用；切片从"新兴 vs 传统"改为"上下游对照"，换取库内可执行性，代价是报告的新兴论断证据等级整体依赖公开来源。否决方案：等待 Bing 降级解除（不可控）；用文库文档作正式引用（权威性不足，只作线索）。
- 后续扩展路线：纺织领域若成为常驻需求，考虑补「数码印花」「智能纺纱」等关键词探库验证；检索源健康检查（连续相关性失败时告警）；文库类域名信誉降权标注。
- 验证：快照跑批 18/18 ok（面料/服装 × 广州/深圳 × 4 维 + 省级分布）；web-search 360 兜底实测返回相关纺织结果且重定向地址已还原；guangdong-textile.md 共 227 行含公开来源摘要 3 条与岗位-技能-专业关联表；`data/README.md` 索引与 `technology-snapshots.md` 关键词表已更新。
