### web-search 相关性判别与编码的两个新失败模式
- **`looksRelevant` 放行噪声（`scripts/web-search.mjs:128-134`）**：判定用 `tokens.some(...)`，只要查询词里任意一个 token 命中标题/摘要即算相关。本轮中文查询含裸年份 token `2026`、英文查询含 `2025`，cn.bing 降级返回的无关页面（蜜桃影视、零售电商站）摘要里带年份，于是 `some` 命中、**360 兜底未被触发**（`search()` 在 `looksRelevant` 为真时直接返回必应结果，`scripts/web-search.mjs:143-152`）。可复用约定：自动化检索尽量避免把裸年份写进 query；后续应把判别改为"忽略纯数字 token + 要求领域 token 命中数占比阈值"。
- **`--fetch` 不解码 GBK 页面（`scripts/web-search.mjs:171-172`）**：抓取按 `toString('utf8')` 硬解，央广网 `cnr.cn`（GBK）返回整段乱码（标题/正文均不可读）。绕行方式为 `curl -s URL | iconv -f GBK -t UTF-8` 再抽取正文；本轮据《一条牛仔裤里的"二次创业"——广州新塘"牛仔之都"焕新记》拿到广东本地集群数字化证据。建议 fetch 侧按 `content-type charset` 或 `<meta charset>` 探测编码，并在乱码时回退 GBK/Big5。
- 可用权威来源（本轮实际引用）：cntac.org.cn《"智"存高远、心中有"数"，2025 纺织服装行业数字化转型大会共商数智新未来》2025-12-06；央广网 2025-12-31（新塘牛仔集群）；黎明职业大学 2025-12-11（全国数字化纺织材料产教融合共同体）；南方网转广东人社 2026-01-13（广州 84 个紧缺职业）；miit.gov.cn《机械工业数字化转型实施方案（2025—2030 年）》解读 2025-08-01；山东科技职业学院 2023-02-27。cn.bing 对纯行业咨询类查询仍普遍降级，但**直连权威站点/站内文章 URL 抓取不受影响**，是当前更稳的取证路径。
