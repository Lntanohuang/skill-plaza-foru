### 本次可用绕行：`--fetch` 走 Bing 搜索结果页
- 直接 `--fetch "https://cn.bing.com/search?q=<urlencoded>"` 返回**渲染后文本**（标题 + 结果摘要 + 域名 + 日期），本轮据此定位到关键政策线索：工信部等三部门印发《轻工纺织产业发展"十五五"规划》、cntac.org.cn 同步发布《…纺织行业解读》（2026-09-29）。这是 045"直连权威站点 URL"之外的**关键词检索兜底**，在 `--query` 失准时可用。
- 局限：`--fetch` 输出会剥离 `<a>`，拿不到深层文章 URL，只有域名与面包屑；RSS 变体（`&format=rss`）因 `text/xml` 不在支持内容类型被拒。因此只能用于"确认某来源存在某主题/某日期"，不能直接点进正文。
- 权威站点直连仍有效：`https://www.cntac.org.cn/`（UTF-8，可读标题与日期）、`http://www.ctei.cn/`（首页要闻可见同一政策标题，与 cntac 形成两站交叉印证）；`https://www.ctei.cn/`（https）fetch failed，`cntac.org.cn` 多数栏目路径（`/zxzx/*`、`/hyzx/`）404，仅首页可达。
