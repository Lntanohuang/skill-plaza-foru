# 开发手记记录规范

每条记录一个主题，放在 `.agents/skills/project-dev-notes/references/<三位编号>-<slug>.md`，并在手记 Skill 的索引中登记。

## 必填结构

```markdown
# <编号> <主题>

- 状态：设计中 / 设计定稿，待实现 / 已实现 / 已废弃
- 动机：要解决的具体问题和约束。
- 约定细节：字段/schema、行为、接入点（实现后写真实 file:line）。
- 成本与取舍：性能、复杂度、维护成本；写明被否决方案及理由。
- 验证：命令、结果、时间；未实测写“待验证”。
- 后续扩展路线：下一步和触发条件。
```

只写可复用的判断和证据。实现前可以先写设计定稿，落地后回填真实路径和验证结果；决策被推翻时保留原记录并标记“已废弃”，注明替代记录。
