# 技术领域与院校专业对照（内置快照）

- 快照性质：**编辑判断快照**（截至 2026-10），专业名称以高职高专通用目录口径整理；正式引用时提示以当年教育部专业目录核定。
- 用途：为“新兴岗位预测 / 培训方向建议”的“匹配专业”列提供对照基础；标注为“内置文档（编辑判断）”。

## 使用规则

- 匹配专业列引用本表时保留“以当年教育部专业目录核定”提示，放第七章口径说明。
- 用户提供了本校专业群清单时，优先按用户清单映射，本表作补充。
- 不得虚构“订单班”“人才需求量”等未提供信息。
