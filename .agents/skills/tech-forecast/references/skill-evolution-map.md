# 技能演进对照（传统技能 → 新兴技能）

- 快照性质：**编辑判断快照**（截至 2026-10）。演进关系与强度为定性归纳，不是实测迁移数据；桑基图引用时必须在图注写明“流量为分析推断（内置文档）”。
- 强度分级：强 / 中 / 弱（用于桑基图流量相对宽度；同图内可比，跨图不可比）。
- 修正规则：岗位库查询命中两类技能关键词共现的岗位名时，可将对应关系佐证为“库内实测（关键词共现）”，其余保持推断标注。

## 使用规则

- 桑基图节点数超过绘图上限时，优先保留与用户关注技术领域相关的行，其余归“其他”。
- 不得把强度映射为具体百分比或人数；流量宽度只表达相对关系。
- 用户关注领域无对应行时标注“内置文档未覆盖”，可用分析推断补充并列出依据。
