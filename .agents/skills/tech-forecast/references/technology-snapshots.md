# 新兴技术清单与成熟度评估框架（内置快照）

- 快照性质：**编辑判断快照**。评级由本技能维护者综合公开行业报道与政策文件的主观归纳（截至 2026-10），不是实测数据；引用时标注“内置文档（编辑判断）”，并提示以岗位库查询与最新公开来源复核。
- 用途：为雷达图评分提供起点维度与依据描述；Agent 应结合岗位库查询修正“产业影响力/人才缺口”维度，并在证据等级中说明修正来源。

## 评估维度（1–5 级，全部维度同一刻度）

| 维度 | 定义 | 评分依据说明 |
| --- | --- | --- |
| 技术成熟度 | 技术本身的工程化与商用成熟程度 | 公开报道中的落地案例规模与标准化程度（编辑判断） |
| 产业影响力 | 对目标区域产业结构的带动范围 | 政策文件与产业链报道的覆盖面（编辑判断） |
| 人才缺口 | 岗位供给缺口的紧迫程度 | 建议用岗位库查询佐证；无查询时为编辑判断 |
| 生态完善度 | 工具链、平台、社区与教学资源可得性 | 开源生态与教学资源可得性（编辑判断） |
| 院校适配度 | 高职/应用本科可切入的门槛与路径 | 岗位入门门槛与实训可行性（编辑判断） |

## 技术清单（按技术领域分组）

### 人工智能与大模型应用

- 代表新兴岗位方向：大模型应用开发、智能体（Agent）开发、AI 数据标注与质检、提示词工程、AI 产品运营。
- 代表新兴技能：大模型 API 与编排、RAG 检索增强、Agent 工具调用、数据清洗与标注管理。
- 评分（编辑判断，待岗位库复核）：技术成熟度 4；产业影响力 5；人才缺口 5；生态完善度 4；院校适配度 4。
- 依据说明：应用层落地案例多、政策推动明确；入门岗位（标注、运营）门槛适合高职切入。

### 具身智能与机器人

- 代表新兴岗位方向：工业机器人运维、机器人集成调试、具身智能数据采集与训练。
- 代表新兴技能：机器人操作系统与仿真、运动控制调试、机器视觉应用。
- 评分（编辑判断，待岗位库复核）：技术成熟度 3；产业影响力 4；人才缺口 4；生态完善度 3；院校适配度 4。
- 依据说明：制造业自动化改造持续；运维与集成岗位对学历门槛相对友好。

### 低空经济（无人机）

- 代表新兴岗位方向：无人机测绘与巡检、低空物流运营、无人机装调检修。
- 代表新兴技能：无人机操控与航线规划、载荷数据处理、空域法规合规。
- 评分（编辑判断，待岗位库复核）：技术成熟度 3；产业影响力 4；人才缺口 4；生态完善度 3；院校适配度 5。
- 依据说明：政策推动快但商业化早期；操控与维护类岗位适合职业院校。

### 新能源汽车与储能

- 代表新兴岗位方向：新能源汽车维修、电池检测与梯次利用、充换电设施运维。
- 代表新兴技能：三电系统诊断、高压安全作业、储能系统集成。
- 评分（编辑判断，待岗位库复核）：技术成熟度 4；产业影响力 5；人才缺口 4；生态完善度 4；院校适配度 5。
- 依据说明：产业规模大、售后网络扩张带来确定性技能缺口。

### 集成电路

- 代表新兴岗位方向：芯片封测工艺、产线设备运维、版图辅助设计。
- 代表新兴技能：封测工艺流程、设备点检维护、EDA 工具辅助使用。
- 评分（编辑判断，待岗位库复核）：技术成熟度 4；产业影响力 5；人才缺口 4；生态完善度 3；院校适配度 3。
- 依据说明：封测与设备端岗位高职可切入；设计端门槛高。

### 数据要素与数据治理

- 代表新兴岗位方向：数据治理工程、数据标注与质检、数据合规审核。
- 代表新兴技能：数据清洗与标准化、元数据管理、标注规则设计。
- 评分（编辑判断，待岗位库复核）：技术成熟度 4；产业影响力 4；人才缺口 3；生态完善度 3；院校适配度 4。
- 依据说明：制度驱动明确；入门岗位以规则执行为主。

## 标准关键词表（岗位库查询口径）

查询工具的谓词语义：`keywords` 之间 AND，`roleTerms` 之间 OR，再整体 AND（roleTerms 用于收窄）。每个技术领域的“新兴切片”与“传统对照切片”各执行一组查询，两组使用同一城市口径（省内优先广州、深圳做城市切片），产出经验/薪资/学历的横截面对比。

| 技术领域 | 新兴切片（keywords） | 传统对照切片（keywords） |

| 人工智能与大模型应用 | `大模型` | `Java`、`软件测试` |

| 低空经济（无人机） | `无人机` | `测绘` |
