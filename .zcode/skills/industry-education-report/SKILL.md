# 产业人才需求观察报告

输出可审查的报告材料：报告 Markdown、结构化 report.json、证据与口径附录、验收结果。模板与数据全部内置于本技能：**禁止联网检索（WebSearch、webReader、Tavily、浏览器），禁止连接 MySQL**。运行时不重跑库、不找网络证据，所有数字来自离线数据文档的既算统计。需要 Word/PDF 时再按可用文档工具导出，并检查导出后的页码、表头、图注；不能把 JSON 合格当作最终文件已验收。

## 选择与对齐

1. 模板读取 [02-报告模板](assets/02-报告模板.md)（复制自仓库 `reports/02-报告模板.md`，2026-09-20 版）：12 章骨架、每章“观点式导语→图N→数据解读→结论框”固定模式、章节→所需数据映射表。02 中提到的配套文档《01-图片信息读取》《03-广东省信息清单》不随技能分发，相关信息一律以 [05 数据快照](references/05-数据库字段摸底与口径.md)为准；两处不一致时以 05 为准，并在 01 章口径边界中说明。仓库 reports/ 原文件更新时同步刷新技能内副本。
2. 数据只读 [05-数据库字段摸底与口径](references/05-数据库字段摸底与口径.md)（复制自仓库 `reports/05`，2026-09-20 查库快照）。引用任何数字必须给出 05 节号（如 §5.1），不得凭记忆改写、不得重算、不得外推 05 未提供的统计。
3. 对齐参数（02 模板参数）：区域、产业、时间窗、基期、编制机构、主数据集。默认广东省、人工智能（AI 切片 v1）、时间窗=库内导入批次 2026-06~07 快照、主数据集=内部岗位库广东在招切片。默认口径是快照，不是最新年度实况。用户改换区域或产业而 05 无对应切片时，相关章节全部登记缺口，不得拿广东全量或 AI 切片数据顶替。
4. 用户提供新模板时以它为主，逐项建立“原模板条款—报告章节—所需数据—验收项”映射，在工作副本内更新 assets/templates.json 章节 ID、标题与顺序，并保存映射与原模板版本；脚本按工作副本模板检查，额外条款逐项人工审核，不能沿用内置模板的通过结果。

## 取数与口径红线

- 05 没有的统计（互斥岗位族/赛道分布、城市×赛道矩阵、岗位×学历×薪酬交叉、AI 切片经验分布与主体数等）只能登记 gaps（责任方=数据侧补算并更新 05），不得编造。§6.1 逐词命中数相互重叠，相加不等于分布。
- 允许的降级：无互斥分类时以“含关键词岗位数（非互斥）”呈现并明示口径，不得称为占比分布。
- 固定口径：create_time=爬虫导入批次≠发布时间；在招记录≠实际录用；经验枚举为“X 年以下”上界桶；薪酬中值剔除 0 与 >100K 后计算；全库 JD 词频为 1/40 抽样推算（±1%），AI 切片为精确值；城市分布含回填与多址未定；来源平台无猎聘、无企业官网，附录 B 按实际渠道改写。
- S10–S12 的外部依据（政策文号、职业标准、院校布点）05 不含且禁网：只能基于 05 内部证据推断并登记缺口，不得编造政策与标准；拟议目标标注“建议目标”。
- 写作前先对照 [数据契约](references/data-contract.md) 的“章节→05 数据映射”表备数；口径红线全表见同文档。

## 生成与验收

按 [结构契约](references/data-contract.md) 写 report.json（edition 固定 `observation`，16 章 S00–S12+附录A/B/C），各章包含 claims；缺数必须写 gaps（责任方、待取字段、影响）。完整示例见 assets/examples/observation/。

运行（路径相对于本技能目录）：

```bash
python3 scripts/report.py validate report.json --output validation.json
python3 scripts/report.py render report.json --output report.md
python3 scripts/report.py verify report.json report.md
```

自动检查失败则修正再生成；默认输出不覆盖已有文件。渲染器只渲染通过结构检查的报告。对已渲染文件的 verify 检查其是否与校验后的结构化报告一致，防止正文变动后沿用旧验收结果。

自动检查只证明结构、引用关联和基本口径字段完整，不能证明引用真实支持结论。交付前逐条人工/Agent 语义审核：对照 05 原文核对每个数值与节号、口径与限制是否一致；判断建议及推断是否超出证据；核对每章“导语→图N→解读→结论框”模式与图下口径注释。将结果写入 review.md，记录审核者、日期、每个 claim 的 pass/fail 和理由；失败的关键结论必须删除、降级或补证。

05 快照下多数交叉分析存在缺口，交付物属“结构合格、有限证据的研究样板”，不得标注为可直接审批的正式报告。最终给出两种独立状态：模板结构是否通过、决策数据是否完备。
