### C-T01 就业质量报告内容框架（全国高校）

- 准确标题：教育部办公厅关于编制发布高校毕业生就业质量年度报告的通知。
- 文号：教学厅函〔2013〕25号；正文落款 2013-11-02，页面生成日期 2013-11-05，发布日期 2013-11-15，避免混写。

## 3. 自动检查建议

硬检查应验证：所有必选章节存在且非占位；每条关键结论有可解析证据ID；证据含发布主体/标题/URL/发布日期或未知说明/访问日期/定位；每个指标有地域、统计期、单位、分母、口径与来源；每图有标题、来源、单位、期间、解释；数据缺失为 null/未披露而非0；学校实绩不得用广东全省数或他校数填入；“建议/推断”不能伪装成观测事实。

人工检查必须保留：引用是否真的支持结论、产业与专业映射是否合理、局部招聘样本是否被过度外推、省级指标是否被错当园区指标、院校内部数据是否获得确认。程序通过不等同于内容真实性审批或官方报送合规认证。


# 政府／园区产教决策报告模板检索记录

检索日期：2026-09-15。检索方式：读取 tavily-search skill；Tavily CLI 返回额度耗尽，改用 web 搜索与官方网页核验。只采用官方来源作为模板依据。

## 1. 结论与适用边界

检索到正式的政府投资项目可行性研究报告大纲；没有核实到同时覆盖产业、岗位、企业、就业、专业课程、招商六主题的广东统一“产教决策报告模板”。本技能应明确声明：**模板为参考官方大纲与广东产业政策形成的决策研究改编模板，并非官方统一模板，也不等同于投资项目报批可研报告。** 用户提供本单位模板时应优先逐项映射；属于正式政府投资项目报批的，应采用完整法定/主管部门大纲及最新要求，不能用本样板替代。

## 4. 校验规则建议（技能自定义质量规则）

1. 检查 G01—G08 每章存在且有实质内容；缺失数据章节保留，并填写缺什么、为什么、影响哪个决策、补采责任和方法。
2. 每条关键事实和实质结论应有稳定 conclusion_id、正文位置、evidence_id；建议须把证据与推导逻辑分别写明。
3. 每条数字记录指标名称、数值/单位、地域、数据期、统计对象/范围、价格口径、来源 URL、发布机构、发布日期/未知说明、读取日期和表/段落定位。
4. 每图至少含标题、坐标或图例、单位、数据期、地域、来源、口径、计算说明；不得只给一张没有底表的图。
5. 政策目标、事实、计算值、招聘样本和分析推断分别打标；不得用产业增长推出岗位缺口人数。
6. 缺失关键供需数据时，结构可以合格，证据充分性必须为 conditional/blocked；自动校验通过不得表述为政府审批通过。
7. 模板映射表记录每项原模板要求、对应输出位置、是否适用、改编理由。章名存在不能替代逐项内容审查。
