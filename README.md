# SKILL 广场 · FORU 风格 Demo

一个无需 npm 的本地静态页面，以浅蓝白底、角色入口和资源卡片展示设计、开发、研究与内容创作类 SKILL。

## 打开方式

下载仓库后，双击 `index.html`，用浏览器打开即可。

不需要联网、Node.js、安装依赖或启动服务器。本项目没有 `package.json`，无需执行 `npm install` 或 `npm run dev`。

## 功能

- 创作者、开发者、研究者、团队四类角色入口，支持键盘切换。
- 页面、架构图、研究报告、旁白视频四类联动示意预览，可暂停自动展示。
- SKILL 名称、用途和标签搜索，分类筛选与排序。
- 详情页与使用指南，调用示例复制反馈。
- hash 地址保存筛选条件，从详情返回可恢复列表状态。
- 桌面与手机响应式布局，减少动态效果适配。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与近似 SVG 插画 |
| `styles.css` | 视觉样式与响应式布局 |

| `README.txt` | 本地使用说明与验证记录 |

## 演示边界

本页面复用 `foru-web-ui` 技能的独立 starter 设计语言和近似插画，不是 FORU 原站源码或截图，不使用原站 API、联系方式或合作背书。

预览是界面示意，不是实际运行结果。下载仓库、正式发布清单、在线执行与账号系统尚未接入；具体依赖、费用和许可以对应 SKILL 的发布资料为准。页面不生成推测日期、版本、评分或下载量。
