SKILL 广场 · FORU 风格本地 Demo

打开方式
只浏览目录和详情：双击 index.html 即可。
直接使用 SKILL：在项目目录运行 python3 server.py，再打开终端显示的地址。
不需要 Node.js、npm 或安装 Python 依赖。
不要执行 npm install / npm run dev；没有 package.json 是正常的。
API 密钥由本地 Python 服务读取，不会写入网页或仓库。

文件
index.html：页面结构与技能自带的近似 SVG 插画
styles.css：FORU 设计语言与响应式样式
skills.js：4 个业务 SKILL 的展示资料、仓库、安装提示词和最小输入示例
app.js：独立任务页、结构化表单、Mock 知识库、API 调用、产物联动、搜索筛选、详情、复制与导航
server.py：本地静态服务与 Youcai API 代理

功能
“直接使用”为 4 个 SKILL 提供独立 URL、专属表单、完成度和执行摘要。
每个任务页右侧提供可搜索、多选的 Mock 知识库；当前不读取或上传真实资料。
顶部菜单按院校管理者、教师、学生、数据团队分组，并直接进入对应 SKILL 工作台。
产业专业、课程教学、实训就业、数据治理四种业务示意；约 5 秒联动切换，可暂停，悬停/聚焦/页面隐藏时暂停。
搜索、分类与排序保存在 hash 地址中；从详情返回可恢复条件。
详情作为二级页面，使用指南与详情均可通过 hash 地址直接打开。
本地复制提供剪贴板兼容处理与成功/失败反馈。

说明
复用 foru-web-ui 技能的独立 starter 设计语言和近似 SVG，不是原站源码或原站截图。
为提高小字可读性，部分弱说明用既有 #4E5969，未沿用过浅的日期色。
预览是原生界面示意，不是实际运行结果。
4 个业务 SKILL 已接入公开 GitHub 仓库入口；直接使用页通过本地代理调用已配置的 Youcai API。
直接使用页不会自动读取仓库脚本、附件或参考文件；完整能力需安装对应 SKILL。
不生成推测版本、日期、评分、下载量。
旧版 skill-plaza-static / skill-plaza-demo 保持不变。
