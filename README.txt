SKILL 广场 · FORU 风格本地 Demo

打开方式
双击 index.html，用浏览器打开即可。
不需要联网、Node.js、npm、安装依赖或启动服务器。
不要在此目录执行 npm install / npm run dev；没有 package.json 是正常的。

文件
index.html：页面结构与技能自带的近似 SVG 插画
styles.css：FORU 设计语言与响应式样式
skills.js：4 个业务 SKILL 的展示资料、仓库、安装提示词和最小输入示例
app.js：角色切换、产物联动、搜索筛选、详情、复制与导航

功能
院校管理者、教师、学生、数据团队四种角色入口；支持方向键与 Home/End。
产业专业、课程教学、实训就业、数据治理四种业务示意；约 5 秒联动切换，可暂停，悬停/聚焦/页面隐藏时暂停。
搜索、分类与排序保存在 hash 地址中；从详情返回可恢复条件。
使用指南与详情可通过 hash 地址直接打开。
本地复制提供剪贴板兼容处理与成功/失败反馈。

说明
复用 foru-web-ui 技能的独立 starter 设计语言和近似 SVG，不是原站源码或原站截图。
为提高小字可读性，部分弱说明用既有 #4E5969，未沿用过浅的日期色。
预览是原生界面示意，不是实际运行结果。
4 个业务 SKILL 已接入公开 GitHub 仓库入口；页面不提供在线执行、账号系统、第三方 API 或业务背书。
不生成推测版本、日期、评分、下载量。
旧版 skill-plaza-static / skill-plaza-demo 保持不变。
