# FORU 页面设计与前端开发

依据 [优才知路公开首页](https://foru-ai.com/) 的实测参考，构建浅蓝白底、蓝色强调、多角色入口和业务资源卡片的中文平台页面。设计规则与前端实现均包含在本技能中。

## 使用方式

- 设计、布局、配色、字体、内容改写：读 [design-system.md](references/design-system.md)。
- 精调颜色、渐变、描边、阴影与状态：读 [color-recipes.md](references/color-recipes.md)。其中源 CSS 配方与插画近似色分开记录。
- 页面开发、交互、组件拆分、移动端：读 [frontend.md](references/frontend.md)。
- 高保真复现、测量争议、技术栈判断：读 [source-observations.md](references/source-observations.md)，按需查看其中的截图与源 CSS。
- 需要可运行起点：使用 [starter/index.html](assets/starter/index.html)、[foru.css](assets/starter/foru.css)、[foru.js](assets/starter/foru.js)。它们是重新编写的风格示例，不是原站源项目。

先明确目标业务、现有框架和必要页面模块。默认复用设计语言并提供可用的响应式布局；仅当用户明确要求逐像素复刻时，才保留原站固定宽度等行为。原站数据会变化，不将一次抓取的全页高度、招聘内容或统计值固化成要求。

## 必须保留的设计特征

1. **浅色科技视觉**：导航、产品面板、资源主体保持白；`#F9FBFF` 用于交替资源区，`#F2F8FF` 用于默认角色入口，`#ECF6FF` 用于标签。`#165DFF` 表达选中态、链接与行动。企业头部、入口悬停、AI 当前项和伙伴玻璃各用对应渐变与阴影，不共用一套材质。
2. **首屏左右分工**：左侧两行深蓝大标题、蓝色结果说明、两枚浅色描边胶囊；右侧为白色基座、半透明蓝青结构与蓝紫 AI 标识。背景在文字附近与下沿淡出为白，饱和色集中右侧插画。文字保留为 HTML，装饰不妨碍阅读。
3. **角色导向**：先按个人、企业、院校、共建者组织入口，再展示对应产品；更换业务时替换角色与产品映射。
4. **卡片有用途差异**：入口卡片突出图标；解决方案突出行业插画；企业卡片有蓝色头部；岗位卡片强调薪资与标签；新闻强调封面、摘要和日期。不要把各区块统一成同一种卡片。
5. **长页有节奏**：共享内容中线、居中区块标题、白色与浅蓝交替。参考桌面内容宽 1200px，普通区块上下各 60px 留白。
6. **交互表达业务关系**：角色切换改变产品列表；AI 功能选择同步标签、图示和进度；产业链卡片扩大当前项；导航提供按角色分组的产品菜单。

细化或高保真复现时，先查看目标模块对应的原站截图，并比较相同状态：默认与悬停入口、展开与收拢方案、当前 AI 功能、菜单展开。按大面积背景与插画光色、组件可见尺寸、文字对齐与层级、描边投影的顺序调整。不能仅凭蓝白配色判断风格相符，也不能将独立示例预览当作原站证据。

## 实现时的判断

- 保留目标项目的框架、路由、图标体系和有效数据接口。原站存在 Nuxt/Vue、Element UI 和自定义 UI 的公开痕迹，但它们不是复用风格的依赖；不声称已获得原仓库或准确版本。
- 参考值按最终可见边界实现。原站角色 Tab 的 CSS 为 `width:160px; padding:0 24px`，实测外宽为 208px；采用全局 `border-box` 后应写 208px，而不是机械复制 160px。
- 保留容易被简化掉的细节：角色 Tab 紧接面板、入口图形由 56px 缩为 36px 但白框保持 56px；方案插画与文字遮罩分层；AI 的 30px 图标、独立标签、贴时间线的进度和右侧界面共用当前状态。具体盒模型见前端参考。
- 区块标题是 34px / 50px 的 Medium 字形，使用系统字体先以 500 核对；Hero 的 900 字重单独使用。弱文字沿用 `#86909C`，需要提高可读性时改用既有 `#4E5969` 并说明调整。插画近似色不能冒称官方 token。
- 把原站的窄屏溢出、未命名控件、鼠标专用状态和静态示例数据列为需要改造的地方。移动端断点是技能建议，不是已验证的原站规范。
- 使用目标品牌的 Logo、业务插画、真实内容。证据截图与原资源 URL 用于核对参考；示例中不用原站 API、第三方登录、原站联系方式或未经确认的业务背书。
- 优先做导航、首屏、角色入口，再按用户业务加入解决方案、功能展示、资源与信任模块。风格迁移不要求照搬整页全部区块。

## 完成标准

在桌面与窄屏实际查看页面；按对应原站截图检查背景淡出、插画比例、标题厚度、卡片材质和选中状态，再检查文字换行、模块中线与图示联动。移动端无横向溢出，浮动入口不遮挡关键内容，键盘可操作菜单与 Tab，减少动态效果模式下内容仍然可见。报告实际验证结果、近似重建的素材与仍需接入的业务能力。
