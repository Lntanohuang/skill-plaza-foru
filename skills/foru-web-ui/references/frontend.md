# 前端实现参考

这些是从页面关系提炼的实现规则。原站痕迹和实测行为见 [source-observations.md](source-observations.md)，颜色集中定义在 [design-system.md](design-system.md)。下文明确标注原站 CSS / 本轮实测的细节；组件组织、断点、可访问性和性能处理属于重建建议。

## 组件边界

将导航、Hero、角色产品面板、方案卡片、能力关系图、功能展示、产业链列表、实体资源卡片、伙伴矩阵、新闻、理由、页脚与浮动服务拆开。共用SectionHeading、Container、Tag和MoreLink；不要用一个包含所有字段的万能卡片组件。

React/Vue/原生均可。数据与显示分开：`roles[{id,label,products[]}]`、`features[{id,title,description,tags[],image}]`、`solutions[{id,title,description,href,art}]`、按实体分类的资源数组。接口暂未接入时明确展示示例，不调用FORU的业务API。

## 状态及事件契约

| 组件 | 最小状态 | 事件 | 显示结果 |
| --- | --- | --- | --- |
| 导航产品菜单 | openMenu | pointer/focus进入、click、Escape、外部点击 | 分组入口展开；触屏也能打开 |
| 角色产品面板 | activeRole | click、左右键、Home/End | Tab颜色、aria-selected与产品列表一致 |
| 解决方案 | activeSolution | pointer进入、focus、触屏选择 | 当前项增宽并显示描述；详情链接单独生效 |
| AI功能展示 | activeFeature、暂停状态 | 选择、计时、可见性、暂停、减少动态效果 | 标题、标签、图示、进度保持同一状态 |
| 产业链 | activeIndustry | pointer进入、focus、触屏选择 | 当前项宽度与遮罩变化 |
| 新闻 | page | 分页按钮 | 三列卡片按页切换 |
| 浮动服务 | 当前服务面板 | 点击、关闭 | 打开目标业务流程或清楚的示例说明 |

角色、功能、产业项采用稳定ID。不要让菜单与页面Tab共享状态，也不要通过DOM文本搜索推断业务状态。

## 视觉细节与组件契约

优先保留可见边界、对齐关系与信息层级，再实现业务数据。数值来源为 [source-css.txt](source-css.txt)；以下额外注明“本轮实测”的值来自浏览器 rendered / computed style。不要把样式表的内容宽、截图中的加载失败或所有组件的圆角统一当作可见规范。

### 标题、Tab 与入口

- **标题层级。** 区块标题实际为34px / 50px、1px字距、`#1F2329`；源字体为 `HP-Medium`，本轮 computed weight 为400，因为 Medium 是字体族的一部分。使用系统替代字体建议先用500，再按字形调整；不要依靠所有标题700–900来表达层级。Hero 的44px / 64px、900是单独的规格。常规资源卡名18px / 26px，角色产品名20px / 28px，功能名20px / 30px，方案名22px / 22px，各自保留差异。
- **标题组不是固定44px空隙。** 原标题下距22px，副标题16px / 23px；“查看更多”另占一行，距前项10px，链接16px / 24px，18px箭头与基线略错开3px。建议 SectionHeading 用独立 title / description / more 插槽，把到卡片的留白交给区块，避免所有模块机械共享同一个 `margin-bottom`。更多入口位于居中标题组下方，不能只改为右上角小链接。
- **Tab 连到面板。** 桌面可见 Tab 为208 × 52px，只有上两角16px；它紧贴面板上边，没有悬浮胶囊的间隔。面板上左角为0，其余22px。源160px是内容宽，转换成 border-box 后仍需208px；同理面板是1200px外宽、左右各40px后剩1120px。个人4项在1120px内以32px间距分配得256px；3项角色应重新均分，而非保留空白第4列。
- **入口 hover 缩图，不缩容器。** 普通图标外框与图形都是56px；hover 外框仍56px、变白底22px圆角，内图缩到36px，标题下距保持14px。背景从近透明白向 `#F2F8FF` 下渐变，边框1px `#DAEAFF`；hover 改为源蓝渐变和白标题。重建建议把同样反馈用于 `focus-visible`，避免只调 `transform:scale()` 连白框一起缩小，或让文字随 hover 跳动。

### 方案、功能与产业链

- **方案是插画卡。** 非当前项采用黑色22px标题与下一行蓝色细箭头，插画延伸至卡片底部；当前项在同一插画上叠加从上部浓蓝到下部透明的遮罩，标题、16px说明变白，详情为白色胶囊。不要把非当前项变成纯渐变底，或用一个大字 / 字符替代整张行业插画。源文字区域上padding40px、左右可见约30px；当前描述上下margin24px。详情源为内容宽112px高34px、padding4px 16px，content-box 换算参考外宽144px / 高42px，再按实际字体核对。图层不得把遮罩盖在文字上；标题、描述、CTA必须仍是HTML。
- **方案收拢是布局变化。** 使用普通与当前项约1:1.74的比例，独立详情链接保持可点击；不将选择按钮包住链接。卡片高352px、圆角16px，宽度变化时插画避免拉伸：背景或图片按同一高度裁切，保留主体；每个场景预设能承受窄项裁切的安全区。移动端改成可读卡片后可直接保留必要描述，不必强行复制 hover 收拢。
- **AI 左侧有内层对齐。** 时间线1px `#DAEAFF`，列表距线26px；每项padding20px 26px，头部30px图标与文字gap10px。描述与标题共用文字左边界，不从整个按钮左端开始。普通标题 `#4E5969`、说明 `#86909C`；选中只将标题与图标染蓝，说明仍次级。当前标签在文字下16px出现，每个独立 `12px / 28px`、左右12px、4px圆角，间距10px；不要合成一整条蓝底字幕。当前白卡边框为 `rgba(194,220,255,.6)`，阴影使用功能专属 token。
- **进度贴时间线。** 源当前伪元素left:-28px、width4px、从top0开始5s向下增长。重建按自己的 border / padding 换算，让蓝线盖在细时间线上，不能漂移到白卡内部。标签出现使当前项比普通项高，建议为整个功能区预留稳定总高度，防止自动切换推挤下方模块；右侧图示固定同一画框尺寸、按 `contain` 显示完整UI，以真实功能差异同步变化。源左右为1:1、gap40px；重建可以流式调整，但不能把右图缩成很小的装饰图标。
- **AI 区块有整体背景。** 原图示是白色界面、蓝色侧栏及重叠的信息小面板，后方有淡蓝环形装饰；功能区向下接全宽蓝色波形 / 渐变统计背景。需要迁移这一模块时，把背景作为区块层，把图示作为内容层；正文保持深色，统计卡保持白色。单纯四行文字加普通白框的示例只能算交互起点，不能声称已经还原原站这一细节。
- **产业链是照片裁切。** 源背景 `center top / auto 100%`，收拢图以高度保持主体比例；当前245px、普通106px、高234px、gap13px、圆角12px。当前遮罩从25%处透明过渡到 `rgba(10,14,28,.6)`，底部内容padding0 24px 28px，白标题24px、24px行业图标、32px箭头。不要给所有普通项叠同样大标题，也不要让展开图失真。一张证据图里的灰色 / 空白图像可能是加载状态；重建必须提供照片或明确fallback，不能把空白当设计。

### 导航、伙伴与页脚

本轮实测导航64px高，白底、`0 5px 10px rgba(0,11,77,.05)`投影；当前一级项蓝字，下沿4px `#165DFF`。菜单打开态应与当前页面状态独立：当“首页”仍为当前页面时，展开的产品项也可以有蓝色强调。重建建议 `aria-current="page"` 表达页面位置，`aria-expanded` 表达菜单；下沿指示固定在导航底边，不能使用 `border` 让布局高度变68px。四列产品菜单沿共享1200px中线展开，分组名、产品名、说明分别成层；内容不是4个大CTA。

本轮 [visual-recheck.json](visual-recheck.json) 补录菜单 CSS：四列gap24px，内层上下padding16px；分组14px/21px、weight500、0.5px字距，下padding8px、margin12px，文字背后6px高 `#D3EDFF` 轻高亮，分组分隔由 `#E5E6EB` 向透明渐隐。产品列表gap8px，每项padding8px 12px、图标24px、图文gap10px；产品名14px/20px、weight600、下距4px，子入口14px/20px弱灰，之间用1px × 12px中性竖线。hover 表面 `#F7F9FC`、产品名变蓝，12px箭头由opacity .5变1。菜单整体白底、`0 12px 32px rgba(0,0,0,.12)` 中性投影是独立例外；触屏建议子入口换行，避免照搬源nowrap造成溢出。

伙伴区外板24px圆角，源白色60%边框、渐变 `rgba(255,255,255,.79)` 到 `rgba(141,208,255,.79)`、blur60px及伙伴专属蓝阴影；内部是白底Logo小板10px圆角。只在伙伴模块使用这套材质，品牌Logo按自身比例contain、统一留白，不强行填满或改成统一蓝色字块。

本轮 [完整伙伴截图](screenshots/desktop-partners.jpg) 补充关系：标题在玻璃板之外、上方白色区域；玻璃下半部后方有全宽饱和蓝背景，上边呈波形，源为背景图。桌面矩阵5列3行是当时15个伙伴的结果。重建用独立背景层与内容层，CSS/SVG波形颜色标为近似值，伙伴数量少时按实际数量排布；不要用普通白祖先上的半透明板代替整个背景结构。

本轮实测页脚主底 `#141933`、组标题 `#FBFCFD`、链接 `#C9CDD4`。结构包括左侧品牌说明、入口、协议、联系、关注分组及独立版权条；迁移按实际业务保留分组，不把原站联系电话、二维码、认证或版权声明复制过去。联系方式的图标与文字保持同行，二维码提供文字替代和真实用途说明。

右侧服务是白色纵向圆角胶囊，蓝色图标 / 小号深字；AI助手独立为76px圆按钮，与长胶囊有间隔，色彩仅在其标识和轻边缘渐变上。建议浮层采用独立 z-index token，在安全区内固定，弹出面板不超过视口；靠近页脚仍不能覆盖联系 / 版权内容。这里的76px来自前轮实测，其余排布关系来自截图观察，具体外距按目标页面边界核对。

## AI展示的计时

原CSS选中项伪元素有5s线性进度，实测当前项会自动变化。它提示约5秒一次的展示节奏；并未审计原站全部计时源代码。

重建时推荐：只有组件在视口内且页面可见时推进；手动选择后从零开始；暂停按钮、focus/hover暂停以及prefers-reduced-motion都应生效。一个计时源同时控制索引和进度，避免多个interval、CSS进度与JS不同步。卸载或离开页面清理定时器、observer与listener。随包 [foru.js](../assets/starter/foru.js) 展示以requestAnimationFrame的累计时间同时驱动进度与选择；React/Vue移植时放到组件生命周期中。

## 布局与CSS

- 全局border-box。参考容器改为 `width:min(1200px, calc(100% - 48px))`；窄屏24–32px总边距。不要继承原站全页min-width:1200px。
- 普通实体资源采用Grid；园区4列、企业/岗位/人才3列、产品按数量自适应。移动端先缩为2列，再按最小可读宽度缩为1列。
- 方案桌面可用flex:1.74的当前项和flex:1的其他项，在352px高度里分配空间；gap22px为起点建议。原420/242宽比约1.74，但参考宽度之和可能超过内容区；最终宽度以Flex布局结果为准。
- 产业链桌面有意做窄项展开；触屏可水平滚动并使用snap。采用比例或flex-basis，不以变宽造成页面溢出。
- Hero插画保持独立装饰层；文字靠正常文档流。移动端标题换行、入口堆叠、插画放到文字之后，不把首屏所有内容固定为460px。
- 固定导航对应scroll-padding-top；浮动服务桌面右距20px，保证与正文有间隔。窄屏隐藏长胶囊，只保留44px以上入口或页内服务。
- 标签区域使用gap和flex-wrap，薪资white-space:nowrap，长地址/企业名有截断策略。卡片内容变化时让同一行等高。
- 源站大量ww-col类、负margin与float不需要继承。样式前缀使用foru或项目命名空间，避免污染既有UI。

## 动效与可访问性

原样式：常规hover约0.2s，上移7px；新闻上移8px；箭头0.3s右移6px；入口内容入场0.5s；AI图示1s淡入/侧移；产业链宽度1s；部分资源有AOS fade-up/zoom-in属性。

复用时缩短或关闭不必要的动效，保持所有必要信息可见。减少动态效果模式关闭自动轮播和入场位移，不用opacity:0使内容永久消失。菜单、Tab和功能项使用真实button，导航使用真实a；keyboard focus有明显描边。隐藏面板移出可访问树，图示提供有意义的替代文字。多张图互换时预留尺寸，避免内容跳动。

## 数据与加载

首屏不依赖下方资源请求；首屏素材提前加载，下面的封面按需加载并保留宽高。图表和长列表在视口附近渲染，图片缺失保留fallback。原站有异步数据使新闻模块在一次返回导航后缺失；重建时应有空态/失败处理，不让整区无解释地消失。

仅为复用视觉时，系统字体、SVG图标和CSS即可，不需要Nuxt运行时、Element UI完整包、原OSS资源或AOS全库。如已有这些依赖，沿用合理部分。

## 交付验证

以原站对应截图逐组件比较：选中 / 未选中入口、四列菜单、展开 / 收拢方案、AI当前项与图示、企业 / 岗位 / 院校卡及页脚。核对背景范围、标题字重、描边与投影、图标白框、文字对齐和插画比例，不能仅凭“蓝白配色”判定风格相符。

检查真实行为：角色切换展示正确产品；键盘切换不会失焦；每个功能项的标签和图示相符；手动选择、自动推进和暂停不冲突；菜单可打开关闭；减少动态效果下内容可读。确认窄屏scrollWidth不大于clientWidth、按钮可点、浮动控件不覆盖CTA。静态示例需说明哪些地方只是演示，实际登录/客服/投递需接入目标业务。

## 随包示例

在技能的 `assets/starter` 目录启动 `python3 -m http.server 8764 --bind 127.0.0.1`，用浏览器访问 `http://127.0.0.1:8764/`。不需要安装 npm 依赖。预览端口可按本地情况调整。

示例覆盖导航、Hero、角色入口、方案展开、四项功能轮播、三类资源卡片、生态模块与页脚；并非原站所有模块的完整副本。Hero、入口图标、行业插画和产品画框为独立 SVG / CSS 近似重建。AI 四项使用共享示意画框、不同标题/标签及少量图形变化，未提供四套真实业务截图。资源区将三种卡片并排说明结构，目标项目仍应按实体分组。伙伴模块标题在玻璃外，波形后方蓝色为近似背景，四个通用协作项不是原站合作Logo或合作背书。产业链、新闻和浮动服务按上面的组件契约在目标项目中实现。

2026-09-14验证结果：技能结构和本地引用完整，JavaScript语法检查通过；角色点击与左右键可切换并更新产品，AI上下键同时更新选中态、图示标题与标签；方案仅一个展开项；暂停保持6秒，恢复后自动推进；移动端菜单与产品分组能打开，Escape关闭并归还焦点。375、390、768、1440px视口下页面scrollWidth均等于clientWidth。减少动态效果规则做了静态检查，未在此次浏览器中切换系统动态效果偏好。

同日细化后的第二轮复验：角色点击与右键切换、方案展开/收拢短标题、AI上下键联动及独立标签、暂停按钮状态、移动菜单/Escape均正常；375、390、768、1440px无页面横向溢出。实际查看了首屏、方案、AI、资源/伙伴/页脚，并核对品牌蓝、AI选中描边、伙伴大板及Logo小板阴影、页脚底色。伙伴标题移至板外后再次确认390px无溢出。计时长等待和系统减少动态偏好未在第二轮重复测试。独立 subagent 使用更新后的技能交付了可实施的首页设计说明，能正确区分源样式、插画近似和响应式建议；其发现的岗位、完整伙伴截图缺口已补充，入口hover仍由源CSS支持。
